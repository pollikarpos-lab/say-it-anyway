# Не бійся говорити · Say It Anyway  — v0.4

**Твоя думка. Твій голос. Навіть неідеально.**

Mobile-first PWA для розмовної практики англійської на біблійному матеріалі.
Тестова версія: **оболонка маршруту на 7 днів + п'ять написаних днів наскрізно**.

| День | Тема | Режим | Що робить людина |
|---|---|---|---|
| 1 | Не бійся · II до Тимофія 1:7 | повторення | слухає й повторює три фрази; аудіо нікуди не йде |
| 2 | Мир усередині тривоги · Від Івана 14:27 | рамка | збирає власне речення з готових варіантів і промовляє |
| 3 | Тривога про майбутнє · Филип'ян 4:6–7 | вільно | відповідає своїми словами про теперішнє |
| 4 | Коли проходиш через воду · Ісаї 43:2 | вільно | розповідає історію про пройдене (минулий час) |
| 5 | Мужність діяти · Ісаї 41:10 | вільно | називає одну справу на цей тиждень (I will…) |
| 6–7 | — | — | контент ще не написаний |

Що змінилося у v0.2 — у `CHANGELOG.md`.

Головна механіка:
> AI не придумує відповідь за мене. Він бере мою думку й допомагає сказати її природною англійською.

## Швидкий старт

```bash
# нічого встановлювати не треба — залежностей нуль
npm run dev          # http://localhost:5173
npm run build        # dist/ + dist/artifact.html
npm run preview      # віддає зібраний dist/
npm test             # модульні тести (вбудований test-runner Node)
```

Потрібен **Node ≥ 20**. `npm install` запускати не треба: `dependencies` і
`devDependencies` порожні.

### Наскрізний прогін у справжньому браузері

```bash
node scripts/serve.mjs 5173 ./dist &
node scripts/e2e.mjs        # 82 перевірки + знімки в screenshots/
```

## Чому без React і Vite

Середовище, у якому збиралася ця версія, **не мало доступу до npm-реєстру
й до жодного CDN** (403 від egress-проксі на `registry.npmjs.org`,
`unpkg`, `cdnjs`, `jsdelivr`). Тому стек — нативні ES-модулі без
складання: вони працюють у браузері напряму, збираються одним скриптом на
40 рядків і не потребують жодної залежності.

Для 15–30 тестувальників це не компроміс, а перевага: немає `node_modules`,
немає версійних конфліктів, деплой — це копіювання папки.

**Якщо захочете перейти на React + TypeScript** — міграція прямолінійна,
бо архітектура вже розділена по шарах:

| Шар | Файли | Що робити при міграції |
|---|---|---|
| Контент | `src/content/*` | переноситься як є (чисті дані) |
| Логіка | `src/lib/*` | переноситься як є (чисті функції) |
| Провайдери | `src/providers/*` | переноситься як є (інтерфейси не змінюються) |
| Екрани | `src/screens/*` | переписати `h(...)` на JSX — механічна робота |
| Роутер | `src/app/app.js` | замінити на react-router |

## Що працює РЕАЛЬНО, а що симулюється

| Частина | Статус |
|---|---|
| Запис голосу в браузері (MediaRecorder + рівень сигналу) | ✅ **реально** |
| Таймер, ліміт 60 с, зупинка, перезапис, видалення | ✅ **реально** |
| Прослуховування власного запису | ✅ **реально** |
| Озвучення англійської (Web Speech API) | ✅ **реально**, голос залежить від пристрою |
| Мовний розбір і «природніша версія» | ⚠️ **набір правил**, не мовна модель. Реально читає ваш текст, але не розуміє змісту |
| Транскрипція голосу | ❌ **демо**: повертає підготовлений текст. Позначено на екрані |
| Текстовий шлях (без мікрофона) | ✅ **реально** — це ваш власний текст, розпізнавання не застосовується |
| Кризовий сценарій | ✅ **реально** (детектор + статичний екран) |
| Фільтр заборонених формулювань | ✅ **реально** (перевірка на виході) |
| Збереження прогресу, видалення даних | ✅ **реально** |
| PWA: manifest, service worker, встановлення | ✅ **реально** (перевірено в Chromium) |
| Шрифт Inter із Google Fonts | ⚠️ **не перевірено**: у середовищі збірки немає доступу до fonts.googleapis.com. Є повний системний фолбек, сторінка коректна і без нього |
| Нагадування / push | ❌ не реалізовано, вибір лише запам'ятовується |
| Синхронне підсвічування слів в аудіо | ❌ не реалізовано |
| Дні 6–7 | ❌ контент не написаний, позначені як «готується» |
| Оплата, адмінка, акаунти | ❌ свідомо поза межами першої версії |

## Режими провайдерів

За замовчуванням — `mock`: **застосунок повністю працює без жодного ключа.**

Щоб підключити справжні STT/LLM/TTS, у `config.js` поставте
`providerMode: 'http'` і `apiBaseUrl` вашого **власного бекенд-проксі**.
Ключі живуть тільки на сервері. Контракт — у `docs/PROVIDERS.md`.

> HTTP-провайдери написані, але **не перевірені на живому сервері** —
> у цьому середовищі не було до чого підключатися.

## Приватність

- Оригінальне аудіо видаляється одразу після транскрипції (`app.js`, `submitVoice`).
- Аналітика має білий список полів: вільний текст фізично не може туди потрапити (`analytics.js`).
- «Видалити всі мої дані» стирає `sia.v1` і `sia.events`; подія фіксується **до** стирання.
- Шифрування **не заявляється**, бо не реалізоване.

## Відомі обмеження

1. Розпізнавання голосу — демо. Головну продуктову гіпотезу («чи люди говорять уголос»)
   перевірити можна вже зараз, якість розбору — ще ні.
2. Розбір за правилами покриває ~22 типові помилки україномовних. Це багато для демо
   й мало для продукту.
3. У вбудованих вікнах (iframe без `allow="microphone"`) запис недоступний —
   застосунок це розпізнає й пропонує текстовий шлях.
4. Тестовано в Chromium. **Safari на iPhone і Chrome на Android не перевірялися** —
   потрібен ручний прогін на пристроях.
5. Inter підключений з Google Fonts. Офлайн (і в середовищі збірки) він не
   вантажиться — сторінка падає на системний шрифт. Це свідомий компроміс:
   на iPhone фолбек — SF Pro, і виглядає він добре.
