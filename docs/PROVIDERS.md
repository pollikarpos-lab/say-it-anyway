# Контракт бекенд-проксі

> **Реалізовано** 19.09.2026 у `worker/index.js` — Cloudflare Worker, який
> роздає і сайт, і `/api`. Базовий URL у продакшені — `/api` того ж
> домену, тож CORS не потрібен. Ключ лежить у сховищі секретів Cloudflare
> як `OPENAI_API_KEY`; у коді, у конфігах і в git його немає.
>
> Моделі: `whisper-1` для розпізнавання, `gpt-4o-mini` для розбору.
> Межі, які стоять до звернення в OpenAI: аудіо ≤ 2 МБ, текст ≤ 2000
> символів, запити лише зі свого ж домену. Головний запобіжник від
> несподіваного рахунку — **місячний ліміт в акаунті OpenAI**.

Клієнт **ніколи** не тримає ключів і **ніколи** не ходить напряму в OpenAI,
Anthropic, ElevenLabs тощо. Він звертається лише до вашого сервера.

Базовий URL задається в `config.js` → `apiBaseUrl`.

## POST /stt

`multipart/form-data`: `audio` (webm/mp4), `lang` (`en`).

```json
{ "text": "This week I am worried about...", "confidence": "high" }
```

`confidence`: `high` | `low` | `unknown`. При `low` клієнт наполегливіше
пропонує перезаписати.

## POST /analyze

```json
{
  "transcript": "...",
  "level": "A2-B1",
  "targets": [{ "id": "worried", "en": "I'm worried about…" }]
}
```

Відповідь:

```json
{
  "corrections": [
    { "kind": "clarity", "before": "I not know", "after": "I don't know",
      "why": "Заперечення через don't." }
  ],
  "improved": "This week I'm worried about my work...",
  "usedTargets": ["worried"],
  "totalFound": 6
}
```

`kind`: `clarity` | `natural` | `grammar`. Клієнт показує **максимум 3** і
ріже зайве сам, але сервер має повертати вже відсортоване за важливістю.

### Обов'язкові вимоги до серверного промпта

1. `improved` — це **та сама думка користувача**, змінена лише форма.
   Заборонено додавати нові факти, поради, духовні коментарі.
2. Не згадувати Бога, віру, молитву в мовному розборі взагалі.
3. Пояснення (`why`) — простою українською, без граматичної термінології,
   де її можна уникнути.
4. Сервер **не отримує** біблійного тексту й не має його переписувати.

Незалежно від промпта, клієнт проганяє `improved` через
`filterAiOutput()` (`src/lib/safety.js`) і **не показує** текст, що не
пройшов перевірку.

## POST /tts

```json
{ "text": "...", "voice": "en-US" }
```
→ `{ "url": "https://.../audio.mp3" }`

## Кризовий сценарій

Якщо `detectCrisis()` на клієнті спрацював, запит `/analyze` **не
надсилається взагалі**. Сервер такого тексту не бачить.

## Змінні середовища

Див. `.env.example`. Клієнтських ключів немає і бути не може.
